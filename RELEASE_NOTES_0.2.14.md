# Release 0.2.14

- Das Migrationsmodul unterstuetzt jetzt eingebettete Salesforce-Logins pro Migration inklusive OAuth-Allow, Benutzername/Passwort, Client-ID-Secret und Rueckfall auf bestehende Instanzen
- Der Migrationstab zeigt eigene Login-Instanzen als Panels mit Verbindungsstatus, letzter Migration und kompaktem Fehlerkontext
- Die Dashboard-Zeitraum-Buttons sitzen jetzt direkt im Header des Charts Datensaetze Verlauf statt separat oberhalb der KPI-Karten
- Die Scheduler- und Monitoring-Validierungen wurden fuer Salesforce-Upsert, Log-Darstellung und Laufzeitauflosung robuster gemacht
